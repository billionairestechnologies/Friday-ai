# Flows

Each flow is the working path for one part of a call. The diagrams in [../diagrams](../diagrams/README.md) draw the same paths.

| Flow | What happens |
|---|---|
| [Discussion](01-discussion.md) | User speaks, Friday answers, Friday waits |
| [Hold or release](02-hold-or-release.md) | Short work stays on the line. Long work leaves it |
| [Making a job](03-making-a-job.md) | From a spoken request to a result |
| [Delivery](04-delivery.md) | Call, app, Telegram, WhatsApp, email |
| [Co-working](05-coworking.md) | The call drives a sandbox or a connected system |
| [Agents and workflows](06-agents-and-workflows.md) | Loops, schedules, and automations from the phone |
| [Persona and memory](07-persona-and-memory.md) | How a turn sounds, and what the next call remembers |
