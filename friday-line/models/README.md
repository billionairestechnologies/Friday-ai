# Working models

These are the records the phone session uses. They are not a second database design. They sit on the Friday runtime the app already uses: entitlements, jobs, build mode, skills, and the scheduler.

| Model | What it decides |
|---|---|
| [Runtime](01-runtime.md) | One brain for every surface |
| [Session](02-session.md) | This call, and the turns inside it |
| [Job](03-job.md) | A piece of work, short or long |
| [Presence](04-presence.md) | Which of the user's systems are connected |
| [Delivery](05-delivery.md) | Where the result is spoken or sent |
| [Entitlements](06-entitlements.md) | Who may call, and how many minutes they have |
