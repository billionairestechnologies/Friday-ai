  • Friday is now a full assistant platform: secure login, saved chats and files, teams, Razorpay billing, connectors, and usage/cost tracking.
  • Users can: sign in, chat, attach files, use Search/Think/Canvas/voice, create Work/Developer projects, connect apps, pay, export or delete data.
  • To go live: apply Supabase migrations 0001–0014, set production secrets, deploy, then check /api/health/ready.

4. How chat works

sequenceDiagram
  actor U as User
  participant FE as Web app
  participant API as Friday API
  participant DB as Supabase
  participant M as AI model
  U->>FE: Message and files
  FE->>API: POST /api/chat with JWT
  API->>DB: Save user message
  API->>M: Stream prompt
  M-->>API: Tokens plus usage
  API->>DB: Save reply and cost
  API-->>FE: Live SSE
  FE-->>U: Answer appears live

6. How Razorpay billing works

sequenceDiagram
  actor U as User
  participant FE as Settings Billing
  participant API as Friday API
  participant RZ as Razorpay
  U->>FE: Pay Pro or Business
  FE->>API: Create order
  API->>RZ: Create order
  API-->>FE: orderId
  FE->>RZ: Checkout
  U->>RZ: Pay
  RZ-->>API: Signed webhook
  API->>API: Verify signature
  API-->>FE: Plan paid
