# Co-working

The user is on the phone. Friday is operating a system that is connected to their account.

## Sandbox

1. They ask Friday to do the work in the sandbox.
2. Presence either attaches the open sandbox or Friday opens one.
3. She operates it from the runtime.
4. A step that finishes in a few seconds is spoken.
5. A step that will run longer becomes a long job. She says so, and the result goes to the channel they chose.
6. Files and links land on the job, so the app can open them too.

## A connected computer or CLI

1. They say "do it on my machine" or name the machine.
2. Presence checks that the CLI or app session is online.
3. If it is, the runtime sends the work there.
4. If it is not, Friday says the machine is offline and offers the sandbox.

The phone does not remote-control a device that is not already connected to Friday. Connecting the CLI or the app is what puts that system on the presence list.
